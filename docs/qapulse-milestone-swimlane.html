QAPulse · QA Process Swimlane

Normal Flow — PM-Initiated, Ungated

Every milestone starts the same way: a PM creates it. From there, FA, Dev and QA each work it through QAPulse's ordinary pages — Requirements, Tasks, Test Case Library, Execution Dashboard. Progress is read off the PM Dashboard rather than pushed through a wizard — nothing here blocks the next step from starting.
