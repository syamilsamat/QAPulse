QAPulse · QA Deployment Pipeline

Pipeline Swimlane — Milestone to Deployed

The 8-step guided pipeline QA runs end-to-end for one milestone: sync requirements, build and approve test cases, execute, sign off, and deploy. Any step is reachable directly — this isn't a strict waterfall.

STEP 1

Create Milestone

Type, phase target dates, environment ENV1–ENV6, "Requires UAT?" toggle.

planned
STEP 2

Sync Requirements

Pulls a Redmine ticket and its sub‑tickets recursively into linked requirements.

STEP 2

AI Analyze

Quality score, risk level, missing items — gated behind a PII confirmation.

STEP 2

Assign Owners

Tag FA / Dev / QA owners per requirement for the Tasks board.

STEP 3

Draft Test Cases

Write test cases against the synced, AI‑analyzed requirements.

STEP 3

Risk‑Based Priority

AI reorders test cases highest‑risk‑first before compilation.

STEP 3

Compile & Submit

Compile selected TCs into an execution file, submit for review.

in_review
STEP 4

Approve Execution File

Any QA reviewer except the submitter — segregation of duties is enforced.

approved
STEP 5

Execute & Log Defects

Run on the Execution Dashboard: Passed / Failed / Blocked, defects raised.

STEP 5

Release‑Risk Assessment

AI reads the real results and predicts release risk & defect leakage.

STEP 6

Sign Off Functional Testing

Formal confirmation that testing is done and critical defects are resolved.

signedOffAt
STEP 7

Upload UAT Sign‑offs

Official UAT documents — only when the milestone requires UAT.

STEP 7

BDD → Test Cases

Optional: turn Gherkin scenarios into regression test cases.

STEP 8

Readiness Checklist

7 gates re‑checked live — requirements through UAT sign‑off.

STEP 8

RTM & Release Notes

Export the traceability matrix; AI drafts the release notes PDF.

STEP 8

All 7 gates met?

Blocks deploy until every earlier step is done

STEP 8

Mark as DEPLOYED

Milestone closes; steps 1–8 become read‑only.

completed
